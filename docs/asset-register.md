# RMB Groundworks asset register

Collected 20 October 2026 from the existing RMB website at the user's request. These are original published RMB assets, resized for delivery; no generated replacement photography or altered logo artwork is used.

Original masters remain outside the repository in the task workspace `work/original-assets/rmbgroundworks/`. Production WebP variants preserve full aspect ratios; crop focal points are selected in layout. Confirm client ownership and publication permissions before production launch. Captions describe visible activities and do not establish project identity, customer, location, date, compliance or results.
